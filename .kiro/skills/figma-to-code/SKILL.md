## 변환 규칙

| Figma 출력 | 프로젝트 변환 |
|-----------|------------|
| 절대 좌표 (x, y) | Flexbox/Grid 기반 레이아웃 |
| px 단위 | Tailwind 유틸리티 클래스 |
| 인라인 컬러 (#F77F4C) | CSS 변수 (var(--color-primary)) |
| Inter / Noto Sans KR | body에서 상속 (직접 지정 금지) |
| 고정 크기 | 반응형 (모바일 → 데스크톱) |
| 정적 배치 | GSAP ScrollTrigger 애니메이션 추가 |

## 워크플로우

1. Figma MCP로 디자인 데이터 가져오기
2. 프로젝트 스택에 맞게 변환
3. 반응형 확장 (380px → 1440px)
4. 애니메이션 추가

- Figma 절대 좌표를 CSS로 그대로 옮기지 말 것
- 빨간색 텍스트는 디자이너 주석 — 프로덕션에 포함하지 말 것
